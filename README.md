# KR Steel Website

A professional corporate website designed for KR Steel Structure Limited, a pre-engineered steel structure manufacturer based in Bangladesh. This project showcases the company’s services, manufacturing capabilities, certifications, workforce culture, and contact channels in a clean, modern, and credible presentation.

This repository is a static front-end website built with HTML and CSS, focused on creating a strong first impression for potential clients, business partners, and hiring managers.

## Project Overview

KR Steel operates in the steel structure and industrial infrastructure sector, providing products and solutions for construction, fabrication, and industrial projects. The website was developed to present the company as a trusted, professional, and growth-oriented organization.

The main objective of the project was to create a polished digital presence that communicates:

- Trust and credibility
- Industry expertise
- Modern manufacturing standards
- Commitment to safety and sustainability
- Strong client communication and service focus

## Why This Project Matters

For a company in a technical and industrial sector, the website is often the first point of contact with prospective clients and partners. This project helps establish a strong brand image by showcasing:

- Business professionalism
- Product and service positioning
- Corporate values and compliance
- Workforce and operational excellence

This is especially important for a company dealing with industrial infrastructure and manufacturing, where trust, quality, and presentation are critical.

## Key Features

- Modern landing page for the company brand
- About Us section with company introduction and credibility messaging
- Virtual Tour section to present the facility and manufacturing environment
- Certification Grid highlighting quality and safety standards
- Workers Wellbeing section emphasizing workforce care and culture
- Contact and enquiry section for customer communication
- Fully responsive design for desktop and smaller screens
- Clean, business-focused visual design using a structured corporate layout

## How to Run the Project

Because this is a static website, you can run it very easily:

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a browser, or use a local preview extension such as Live Server in VS Code.

Example:

```bash
git clone https://github.com/Maslenia-Mubarrat/KR_STEEL_WEBSITE.git
cd KR_STEEL_WEBSITE
```

Then open `index.html` in your browser.
